# REQ-007: 薄い紙の両面印刷における裏写り（裏透け）除去・軽減機能

- **ステータス**: `進行中`
- **優先ターゲット**: Brother × macOS（汎用 eSCL 機器・Windows 対応を考慮）
- **元要件（原案）**: [`docs/requirements/drafts/20261117.md`](./drafts/20261117.md)
- **依存する先行要件**: [`REQ-003`](./REQ-003-fast-preview-scan.md)（`REQ-006` は実機ターゲット入手後に後続統合できるよう疎結合で先行実装）

## 1. 背景・目的

`docs/requirements/drafts/20261117.md` の「色合い調整」における以下の要件を実現する。
- **「紙の薄さによって、両面印刷されている場合に裏が透けてしまうのも調整してくれる機能があるとよい」**
- **プレビュー画面上で裏透けがどの程度軽減され、表面の文字や図版がどう見えるかを保存前に確認できること**

雑誌、チラシ、薄い書籍、両面印刷されたコピー用紙などをスキャンすると、スキャナの強い光源が紙を透過して裏面の印刷内容が淡いグレーや反転文字として写り込む（裏写り / Show-through / Bleed-through）。これを背景紙の地色（紙白）の分布推定と局所コントラスト・トーンカーブ制御によって、表面の本来の文字・イラスト・写真の階調を損なわずに自然に除去・軽減する。

## 2. 要件概要とスコープ

### 実施すること（In Scope）
- スキャン画像の輝度・色度ヒストグラムから「紙の地色（背景ピーク）」と「裏透けによる中間〜高輝度の薄い写り込み領域」を自動推定するアルゴリズムの実装
- 表面の濃い文字や図版のエッジ・色合いを維持したまま、裏透け領域を紙本来の地色（白または元の紙色）へ滑らかに馴染ませる裏写り除去フィルタ（`BleedThroughRemover`）の実装
- 紙の厚さや原稿の種類（文字中心の書類 / カラー雑誌・写真混在）に応じて、自動推定＋手動で強度（0〜100%）および「紙の地色を純白にするか元の紙色を残すか」を調整でき、プレビュー画面へ即座に反映する UI の実装

### 今回のブランチでは実施しないこと（Out of Scope / 別要件へ分割）
- 表面と裏面の2枚のスキャン画像を位置合わせして差分を引く両面同時スキャン専用の減算処理（将来拡張とし、本要件では片面スキャン1枚の画像からでも単体で機能する実用性の高い裏透け除去を実装する）

## 3. 完了条件（Acceptance Criteria）

- [ ] 薄い両面印刷の原稿をスキャンした際、裏写り除去を有効にすることで裏面の透けが大幅に目立たなくなること
- [ ] 表面の文字のかすれやカラー図版の白飛びを抑えつつ、プレビュー画面上で除去強度をリアルタイムに微調整して確認できること
- [ ] 確定した裏写り除去設定が本スキャン保存および連続スキャン時にもそのまま適用されること

### タスク 1: 紙の地色推定と適応的トーン制御による裏写り（裏透け）除去アルゴリズムの実装

- **状態**: `[x] 完了`
- **実装内容**:
  - Lab / YCrCb 色空間および輝度ヒストグラム解析により、原稿の「紙の地色（Paper Base Color）」と「裏透け成分の輝度帯」を自動推定する処理を実装する
  - シグモイド系の滑らかなハイライト圧縮・ソフトしきい値処理とエッジ保護フィルタ（バイラテラル / ガイデッドフィルタ相当）を組み合わせ、表面のテキストや図版の輪郭・中間調を保ちながら裏透け部分のみを紙の地色へ収束させる `BleedThroughRemover` を実装する
- **提案コミットメッセージ**:

```text
feat(imaging): 紙の地色推定とエッジ保護による両面印刷の裏写り(裏透け)除去フィルタを実装

## 背景・目的
薄い紙の両面印刷原稿をスキャンした際に裏面の内容が透けて写り込む現象（裏写り）を抑え、表面の文字や図版を読みやすく綺麗な状態で保存できるようにするため（REQ-007 タスク1）。

## 変更内容
- `src/open_escl_client/imaging/bleed_through.py` を追加し、ヒストグラム解析による紙の地色（背景色）の自動推定ロジックを実装
- 表面の濃い文字・線画・写真領域を保護しつつ、高輝度〜準高輝度帯に現れる淡い裏透け成分を紙の地色または白へ滑らかに補正する `BleedThroughRemover` を実装
- 裏写りを模した合成原稿画像を用いて、表面コントラスト維持と背景ノイズ低減を検証する単体テストを追加

## 影響範囲・備考
- 片面スキャン1枚の画像から単体で動作するため、原稿台（Platen）でのプレビュー・本スキャンでもそのまま利用可能
```
