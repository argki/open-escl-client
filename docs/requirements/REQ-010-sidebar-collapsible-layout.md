# REQ-010: 左サイドバーの折りたたみ整理と操作頻度別グルーピング

- **ステータス**: `進行中`
- **優先ターゲット**: Brother × macOS（クロスプラットフォーム・汎用eSCL拡張を考慮）
- **元要件（原案）**: [`docs/requirements/drafts/20261120.md`](./drafts/20261120.md)
- **依存する先行要件**: [`REQ-007`](./REQ-007-bleed-through-removal.md), [`REQ-008`](./REQ-008-config-persistence-and-defaults.md)

---

## 1. 背景・目的

機能追加に伴い左サイドバーの項目数が増え、毎回使う項目（スキャナ選択、用紙サイズ、保存設定、検出パターン／感度・比率など）と、普段ほとんど触らない詳細項目（スキャナ再検索・手動接続、各種 ON/OFF トグル、余白・角度微調整、画質・裏写り除去の詳細スライダー等）が同じ階層に縦長に並んで見づらくなっている。

操作頻度の低い項目を折りたたみ可能なセクション（アコーディオン／詳細設定エリア）に整理し、画面をスッキリさせつつ必要なときだけ展開できるようにする。

## 2. 要件概要とスコープ

### 実施すること（In Scope）
- 再利用可能な折りたたみセクションコンポーネント（例: `CollapsibleSection.qml`）を実装する
- 左サイドバー内で以下の操作頻度が低い項目を折りたたみ表示（初期状態：折りたたみ）へ整理する：
  1. 「1. スキャナ選択」内：**スキャナを再検索・手動 IP/URL 接続**（「接続・再検索の詳細」折りたたみ）
  2. 「3. トリミング・角度・自動回転」内：**自動トリミングを有効にする / 複数枚の原稿を自動分割する / 自動向き補正**（詳細オプション折りたたみ）
  3. 「3. トリミング・角度・自動回転」内：**余白の微調整 / 選択枠の角度調整（＋90°回転等）**（位置・余白・角度の詳細調整折りたたみ）
  4. 「4. 画質・裏写り（裏透け）除去」：**セクション全体または詳細設定の折りたたみ**（かつ `REQ-008` と連携しデフォルトで裏写り除去・背景白化をどちらも ON に保つ）
- 折りたたみ開閉状態の永続化（任意で `UserConfig` とも連携）と既存レイアウト幅制約の維持

### 今回のブランチでは実施しないこと（Out of Scope / 別要件へ分割）
- プレビューキャンバスの拡大縮小・枠ドラッグ改善（`REQ-009` で実施）
- 保存フォーマット拡張・OCR 機能（`REQ-011`, `REQ-012` で実施）

## 3. 完了条件（Acceptance Criteria）

- [ ] 初期表示時に上記 7 種類の低頻度操作項目が折りたたまれた状態でスッキリ表示されること
- [ ] 折りたたみヘッダーをクリックすることで即座に展開・再格納でき、パネル内の各種ボタン・チェックボックス・スライダーが正常に操作できること
- [ ] 画質・裏写り除去が折りたたまれた状態でも、デフォルトで「裏写り軽減」と「背景白化」の両方が ON で適用されていること
- [ ] Brother × macOS 環境（またはモック検証）で意図通り動作すること
- [ ] 折りたたみ展開時もサイドバーが右のプレビューキャンバスを侵食しないこと
