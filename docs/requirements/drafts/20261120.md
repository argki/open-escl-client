##　要望

- 前回設定した項目が次回起動すると初期状態にリセットされてしまわないようにしたい
  - 逆に初期状態にリセットする機能もほしい
- 高速プレビュー時の解像度を指定できるようにしたい
- プレビューキャンバスの拡大縮小をマウスホイールでもできるようにしたい
  - 上下左右の移動はドラッグ&ドロップで問題なし。念のためスクロールバーがあった方がいいかも
- 高速プレビュー時、切り出し結果を大きくして見たい時があるので、下のエリアにあるプレビューをクリック時には、上にその結果が出るようにしたい。また、下のエリアの左側に、全体像に戻すための小さなプレビューも欲しい。
- プレビューキャンバス上で検出枠を調整したい時に、スムーズに調整できないため、原因調査してほしい
  - 設定した比率を維持してして調整できるようになっているかも気になる
- ネーミングルールにデフォルトでtimeも入れたい
- 出来るだけ精度の高いOCRを取り入れたい(日本語の精度が高いモデルがいい)
  - そこからネーミングを抽出する機能もあるといい
- 保存ファイル形式のバリエーションを増やしたい
  - 一般的な画像形式は網羅したい
- 初期状態のウインドウサイズだと、プレビューキャンバス右上の拡大縮小ボタンや各カードをクリックして選択...の文字がウインドウから右側にはみ出てしまうため、はみ出ないようにしてほしい。
- 左側のメニューがごちゃごちゃしてきたので操作する頻度が少なそうな項目は折りたたみ表示されるようにしたい。操作頻度が低いと感じた項目は次のとおり
  - スキャナを再検索、接続
  - 自動トリミングを有効にする
  - 複数枚の原稿を自動分割する
  - 自動向き補正
  - 余白の微調整
  - 選択枠　の角度調整
  - 画質・裏写り除去(デフォルトでどちらもONにしておいてほしい)
